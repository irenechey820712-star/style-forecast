# 가상 피팅 배포 가이드

**"내 착용 이미지 만들기"** 버튼을 실제로 동작시키는 방법입니다.
이 저장소를 Vercel에 올리면 앱과 `/api/tryon` 함수가 **한 번에** 배포되고, 코드 수정 없이 버튼이 켜집니다.

```
브라우저 앱  ──POST /api/tryon {image, prompt}──▶  api/tryon.js  ──▶  이미지 편집 모델(Replicate)
     ▲                                                                        │
     └───────────────────  { image: "<url>" }  ◀──────────────────────────────┘
```

- 업로드한 사진 + (앱이 자동으로 만든) 영문 지시문을 이미지 편집 모델에 넘겨, 얼굴·체형은 유지하고 옷만 추천 코디로 바꿔 그린 사진을 받습니다.
- 기본 예시 모델: **FLUX Kontext** (옷 사진 없이 텍스트 지시만으로 편집). `api/tryon.js`의 `callModel()`만 바꾸면 다른 모델/제공자로 교체 가능.

---

## 1) Replicate API 토큰 발급 (이미지 생성용, 유료)

1. <https://replicate.com> 에 GitHub 계정으로 로그인
2. 우상단 프로필 → **API tokens** → 토큰 복사 (`r8_...`)
3. **Billing** 메뉴에서 결제 수단 등록 (이미지 1장당 대략 수십 원, FLUX Kontext Pro 기준 약 $0.04)

## 2) Vercel에 저장소 배포

1. <https://vercel.com> 에 GitHub 계정으로 로그인
2. **Add New… → Project** → `style-forecast` 저장소 **Import**
3. 설정 화면에서 **Environment Variables** 펼치고 추가:

   | Name | Value |
   |---|---|
   | `REPLICATE_API_TOKEN` | 1번에서 복사한 `r8_...` 토큰 |
   | `TRYON_MODEL` | *(선택)* `black-forest-labs/flux-kontext-pro` |

4. **Deploy** 클릭 → 1~2분 후 `https://style-forecast-xxxx.vercel.app` 주소가 나옵니다.

끝입니다. 그 Vercel 주소로 앱을 열면 사진 업로드 후 **"내 착용 이미지 만들기"** 버튼이 바로 동작합니다.
(코드의 `TRYON_ENDPOINT`가 `github.io`가 아닌 도메인에서는 자동으로 `/api/tryon`을 사용하도록 돼 있음)

## 확인 / 문제 해결

- 버튼을 눌렀는데 *"REPLICATE_API_TOKEN 환경변수가 없습니다"* → Vercel 프로젝트 **Settings → Environment Variables** 에 토큰을 넣고 **Redeploy**.
- *"생성 시간 초과"* → 모델이 느린 경우. 다시 시도하거나 `vercel.json`의 `maxDuration`을 60으로 유지(Hobby 플랜 상한).
- *402 / billing 관련 오류* → Replicate에 결제 수단이 등록돼야 합니다.
- GitHub Pages(`irenechey820712-star.github.io/style-forecast`)에서는 백엔드가 없어 버튼이 안내만 표시하는 게 정상입니다. 가상 피팅은 Vercel 주소에서 사용하세요.

## 비용·개인정보

- 이미지 생성은 **호출당 과금**됩니다. 남용이 걱정되면 `api/tryon.js`에 IP당 호출 제한을 추가하세요.
- 업로드 사진은 Vercel 함수 → Replicate → 모델로 전송됩니다. 미성년자 사진 처리 시 각 서비스 약관을 확인하세요.
- 토큰은 **절대 프런트엔드(`style-dossier.html`)에 넣지 마세요.** 반드시 서버 환경변수로만.

## 로컬 테스트

```bash
npm i -g vercel
vercel dev          # http://localhost:3000  (앱 + /api/tryon 함께)
```
