# 스타일 포캐스트 (Style Forecast)

MBTI 성향 · 상황(TPO) · 퍼스널 컬러를 규칙 기반으로 매칭해 어울리는 스타일 TOP 3와
착용 일러스트를 만들어 주는 단일 파일 웹앱입니다.

## 구성

| 경로 | 설명 |
|---|---|
| [`style-dossier.html`](style-dossier.html) | 메인 앱. 파일 하나로 동작(빌드 불필요). 브라우저로 바로 열면 됨 |
| [`virtual-tryon/`](virtual-tryon/) | 업로드한 사진에 코디를 입힌 이미지를 생성하는 서버리스 함수 + 배포 가이드 |
| [`examples/`](examples/) | 초기 기획 목업 이미지와 원본(`스타일 포캐스트` v1) 소스 |

## 기능

- **입력**: MBTI 4지표 토글 · 성별 · 연령대 · 상황(발표/데일리/데이트/나들이/행사) · 선호 스타일 · 회피 항목
- **추천 엔진**: 10개 스타일 아키타입에 대해 `MBTI 0.35 + TPO 0.20 + 트렌드 0.20 + 연령 0.15 + Z세대 0.10` 가중 점수 → 상위 3개
- **착용 일러스트**: 조건에 따라 실시간 조립되는 벡터(SVG) 크로키. 이미지 생성 AI를 호출하지 않음
- **퍼스널 컬러**: 업로드 사진의 평균 톤에서 웜/쿨·계절을 추정, 어울리는 색 제시 + 톤이 맞는 스타일에 점수 보정
- **스타일 무드보드**: 키워드·팔레트·일러스트·내 사진을 한 장의 PNG로 내보내기
- 다크 모드, 키보드 접근성, `prefers-reduced-motion` 대응

## 실행

```
style-dossier.html 파일을 브라우저로 열면 끝.
```

정적 호스팅(GitHub Pages 등)에 올리려면 이 저장소를 그대로 배포하고
`style-dossier.html`을 진입점으로 지정하면 됩니다.

## 실제 가상 피팅(선택)

사진에 코디를 입힌 포토리얼 이미지는 이미지 생성 API가 필요하며 브라우저 단독으로는 불가능합니다.
[`virtual-tryon/README.md`](virtual-tryon/README.md)의 안내대로 서버리스 함수를 배포하고,
`style-dossier.html` 상단의 `TRYON_ENDPOINT`에 함수 URL을 넣으면 결과 카드의
**"내 착용 이미지 만들기"** 버튼이 활성화됩니다.
